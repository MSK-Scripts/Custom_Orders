# MSK Scripts Custom Orders

FiveM scripts that MSK Scripts wrote on request for single servers, now free for everyone.

Most of them were built for ESX and for one server's setup, so expect to adjust configs, items
or framework calls before they run on yours.

**Status:** archived. These scripts get no updates, no bug fixes and no support. Use them as
they are.

## Scripts

| Script | Description |
|---|---|
| [msk_carkick](msk_carkick) | Menu that shows all players inside the car and kicks them out |
| [msk_deathradar](msk_deathradar) | Creates blips for dead players |
| [msk_discordRichPresence](msk_discordRichPresence) | Displays some information about your server in Discord |
| [msk_lifeinvader](msk_lifeinvader) | Place advertisements |
| [msk_noHud](msk_noHud) | Status notification |
| [msk_personalmenu](msk_personalmenu) | Personal menu |
| [msk_rgbHeadlights](msk_rgbHeadlights) | Changeable vehicle headlights with an item |
| [msk_saveCoordMenu](msk_saveCoordMenu) | Admin menu to save coords in a menu |
| [msk_seller](msk_seller) | Selling items |
| [msk_storage](msk_storage) | Storage system |
| [msk_trackphone](msk_trackphone) | Track a player by their phone number |
| [msk_usedcardealer](msk_usedcardealer) | Used car dealership |
| [msk_vehicleShowRoom](msk_vehicleShowRoom) | Show room for vehicles |
| [msk_vehicleclothing](msk_vehicleclothing) | Change clothes at the trunk of a vehicle |
| [msk_vehicleregistration](msk_vehicleregistration) | Registration office for vehicles |
| [msk_vehicleseller](msk_vehicleseller) | Sell your vehicles |

Scripts that are still maintained are listed in the
[MSK Scripts organization](https://github.com/MSK-Scripts), older ones in the
[FiveM archive](https://github.com/MSK-Scripts/fivem-archive).
